# Phase 2 — Time Locker 基本描述

## 一句话定位

Time Locker 是建立在 Phase 1 Task Tracker 之上的任务执行时间记录能力，让用户取得 / 认领 Phase 1 Task，并记录实际执行的 Start Time 与 End Time。

## 当前阶段

Phase 2 目前只记录高层产品方向，尚未开始正式 PRD。

## 核心流程

Phase 1 Task → Claim → Start → End → Time Locker Record

## 与 Phase 1 的关系

Phase 2 使用 Phase 1 的 Task 作为基础数据来源，不重新建立另一套独立 Task。

## UI 方向

初步考虑采用类似 Microsoft Lists 的列表 / 表格方式呈现 Task；最终 UI Design System 尚待 Phase 2 正式定义。

## 尚未确认

- 多 Task 同时 Locker
- Claim / Assigned 状态
- Pause / Resume
- 多段时间记录
- End 后重新 Start
- 是否影响 Phase 1 Status
- 多用户并发
- 时间统计 / 报表
- 时间修正
- 审核 / 锁定
- Export
