# 01 基本描述

## 一句话定位
Task Tracker 是独立的 Single Page Web App，以 SQLite 保存任务，以 DataTables 提供 Microsoft Lists / Power Apps 风格的任务列表，支持每周任务查看、REST API CRUD 与 Excel Export。

## Phase 1 目标
- 简单 Task Listing 与每周工作汇报。
- Web App + SQLite。
- REST API Task CRUD。
- 当前 View Export to Excel。

## 技术约束
- Single Page HTML + JavaScript
- SQLite
- DataTables
- Malaysia Time UTC+8
- Weekly boundary：Monday 00:00:00 至 Friday 23:59:59
- 不做 physical delete
- Phase 2 暂不定义

## 核心字段
| Field | Rule |
|---|---|
| Task ID | `TSK-0001`，系统产生、永久唯一、不可重用 |
| Customer Name | 必填、Dropdown、最多16个 Customer |
| Task Title | 必填、单行、最大100字符 |
| Task Description | 可选、单行、最大255字符 |
| Note | 可选、多行、最大1,000字符 |
| Created | 系统产生、只读、决定 Week |
| End | 系统产生、只读；Closed/Deleted 时记录，Active 时 NULL |
| Status | Work in Progress / Pending with Customer / KIV / Closed / Deleted |

## 已确认
- New Task：Popup + Create/Cancel；Status 默认 KIV。
- Edit：Popup + Blur Auto Save；Close 直接关闭。
- Delete：Status=Deleted 的 Logical Delete。
- 不使用 Action Column / Checkbox / Bulk Action。
