# 03 范围边界

## 产品形态
- 独立 Web App
- Single Page HTML + JavaScript
- DataTables
- SQLite
- Microsoft Power Apps / Microsoft Lists 风格

## MVP
| 能力 | 范围 |
|---|---|
| Weekly Task | Carry Over + New This Week；Overall Total；不分页 |
| Current Week Status | WIP / Pending / KIV / Closed 四组；Overall Total；不分页 |
| Show All Data | 全部记录含 Deleted；25/50/100 Pagination |
| Search | Task ID / Customer / Title / Description / Note；Contains；Case-insensitive；Enter 执行 |
| New Task | Popup；Create / Cancel；Status 默认 KIV |
| Edit Task | Popup；Blur Auto Save；Close |
| Customer | Dropdown Add/Edit；最多16个；颜色唯一 |
| REST API | POST / GET / PATCH / DELETE；DELETE 为 Logical Delete |
| Excel | 当前 View 当前结果；单 Sheet |

## 关键规则
- Weekly Task：Carry Over = Created Week < Current Week 且 Status ≠ Closed/Deleted；New This Week = Created Week = Current Week 且 Status ≠ Deleted。
- Current Week Status 只看 Current Week Created，Deleted 排除。
- Weekly Task Total = Carry Over + New This Week。
- Current Week Status Total = WIP + Pending + KIV + Closed。
- 两个 Weekly View Overall Total 必须一致。
- Weekly Views 排序：Customer ASC → Task ID ASC。
- Show All Data 默认 Task ID ASC。
- 任意 Status 可直接转任意其他 Status。
- Closed/Deleted → End=当前时间；Active → End=NULL。
- Closed→Deleted、Deleted→Closed 均以新的状态时间覆盖 End。
- Deleted→Active 清空 End。
- Customer 名称比对：Trim + Case-insensitive。
- Customer Name 改名后历史 Task 显示最新 Name/Color。
- Customer 不可删除。
- 不做 Physical Delete。
