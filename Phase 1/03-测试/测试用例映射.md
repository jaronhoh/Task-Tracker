# Phase 1 测试用例与验收标准映射

## 1. 文档说明

- 来源：`Phase 1/02-PRD/PRD文档.md`（验收标准逐条映射）。
- 范围：F01–F05，共 187 条 PRD 验收标准；另增加 D019 的定向一致性测试。
- 状态：所有用例初始为 `Not Run`；本文是测试设计，不代表已执行或通过。
- 时间基准：Malaysia Time (UTC+8)。
- 测试原则：检查操作结果、数据库最终值、API 响应（适用时）及是否出现部分更新；不得只凭 UI 提示判定数据正确。
- 测试数据：使用隔离测试数据；需要边界时间时，固定测试时钟或明确记录测试执行时的 Malaysia Time。

## 2. 测试结果状态定义

| 状态 | 含义 |
|---|---|
| Not Run | 尚未执行 |
| Pass | 实际结果符合预期 |
| Fail | 实际结果不符合预期 |
| Blocked | 环境或前置条件阻塞 |
