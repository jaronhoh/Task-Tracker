# P0 核心一致性测试用例

## 1. 测试说明

- 本文将优先级最高的数据一致性场景细化为 16 条独立测试用例。
- 时间基准：Malaysia Time (UTC+8)，以服务端时间为准。
- 所有用例初始状态为 `Not Run`；测试设计完成不代表已执行或通过。
- 涉及并发、事务回滚、ID 永不复用的用例需要隔离测试环境、API/数据库验证或故障注入能力。
- 每次执行应记录环境/版本、请求与响应、测试时间、Task ID、数据库前后快照及缺陷编号。

## P0-001 — Active KIV + End 非空自动纠正

- **关联 PRD / 决策：** D019 / AC-F01-03-08
- **测试类型：** API/数据库
- **前置条件与数据：** 建立 Status=KIV、End 非 NULL、Created 不晚于服务端当前时间的 Task，记录原始记录。
- **执行步骤：**
  1. 通过服务端提交合法的 Note 更新；读取 Task 并比较字段。
  2. 检查响应与持久化记录，并记录证据。
- **预期结果：** 请求成功；End 自动纠正为 NULL；Status、Task ID 正确保留；Note 更新成功；无部分更新。
