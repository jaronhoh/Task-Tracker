## 已确认决策

N01–N120 均已 Resolved。

### N121 — View 3 Edit Time
已确认：
- Show All Data 的 Action Bar 增加 `Edit Time`。
- 可修改 `Created` 与 `End`。
- 一般 Edit Task 不允许修改 Created / End。
- Active Task 的 End 原本为空时，Edit Time 必须先弹 Warning Dialog。
- 用户必须选择 Yes 后才可以进入 End 编辑。
- 已 Closed / Deleted 的 Task 已有 End，可直接修改 Created / End。

### N122 — Active Task 设置 End 后的 Status
已确认：
- Active Status：Work in Progress / Pending with Customer / KIV。
- Active Task 原本 End 为空。
- 用户通过 Edit Time 设置 End 后，系统必须询问：
  `Should this Task be Closed or Deleted?`
- 用户选择 Closed → Status = Closed。
- 用户选择 Deleted → Status = Deleted。
- 不允许保存 Active Status + 有 End 的不一致数据。
- 如果 Task 原本已经 Closed 或 Deleted，修改时间时保持原 Status，不重新询问。
