# 产品定型稿（Product Shipping Brief）

## 1. 一句话定位
一个独立的 SQLite + Single Page HTML/JavaScript Task Tracker，以 DataTables 提供 Microsoft Lists / Power Apps 风格任务管理，并支持 Weekly Views、REST API CRUD 和 Excel Export。

## 2. 目标用户
需要记录、跟进和每周汇报工作任务的 Task 使用者。

## 3. 核心场景
- 建立 Task
- 编辑并自动保存
- 查看 Weekly Task
- 查看 Current Week Status
- 查看 / 搜索全部历史
- Customer Add/Edit
- REST API Task CRUD
- 当前 View Export Excel

## 4. 产品形态
- Web App
- Single Page HTML + JavaScript
- SQLite
- DataTables
- Malaysia Time UTC+8
- 顶部 View Tabs
- New/Edit 为约800px 中央 Popup

## 5. MVP 范围
### Task
Task ID、Customer Name、Task Title、Task Description、Note、Created、End、Status。

### Views
- Weekly Task：Carry Over / New This Week
- Current Week Status：WIP / Pending / KIV / Closed
- Show All Data：全部记录含 Deleted，25/50/100 Pagination

### Customer
最多16个，固定唯一颜色；Dropdown 内 Add/Edit；不可删除。

### REST API
POST / GET / PATCH / DELETE；DELETE 为 Logical Delete。API Response 直接 Resource JSON；Status 使用完整文字。

### Excel
当前 View 当前结果，单 Sheet，`TaskTracker_[ViewName]_YYYYMMDD.xlsx`。

## 6. 页面与主流程
View → New Task / Edit Task → Status 生命周期 → Search → Export。
Deleted 不出现在两个 Weekly Views，但保留于 Show All Data；恢复直接修改 Status。

## 7. 数据与权限
Task 与 Customer 为核心对象。Phase 1 不定义复杂权限体系。

## 8. 暂缓范围
Phase 2、Bulk Action、独立 Customer Management 页面、Physical Delete、复杂权限。
