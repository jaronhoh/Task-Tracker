# 04 页面流程

## 页面 / View
顶部 Tabs：
`Weekly Task | Current Week Status | Show All Data`

三个 View 都提供 `+ New Task` 与 `Export to Excel`。

## Weekly Task
- 顶部 Overall Total
- Carry Over (n) 独立表格
- New This Week (n) 独立表格
- Deleted 排除
- 不分页
- Customer ASC → Task ID ASC

## Current Week Status
- 顶部 Overall Total
- Work in Progress (n)
- Pending with Customer (n)
- KIV (n)
- Closed (n)
- 四组独立表格，0 仍显示
- Deleted 排除
- 不分页
- Customer ASC → Task ID ASC

## Show All Data
- 全部 Task，包括 Deleted
- DataTables Pagination：25 / 50 / 100
- 默认 Task ID ASC
- Action Bar 增加 `Edit Time`
- `Edit Time` 用于修改选中 Task 的 `Created` / `End`

### Edit Time 流程

#### 情况 1：Task 当前为 Active Status，End 为空
Active Status 包括：
- Work in Progress
- Pending with Customer
- KIV

流程：
1. 用户在 Show All Data 选择一个 Task。
2. 点击 Action Bar → `Edit Time`。
3. 系统发现 `End = Empty`。
4. 先弹出 Warning Dialog：
   > End time is currently empty. Do you want to set an End time for this Task?
5. 用户选择 **Yes** 后，才允许进入时间编辑。
6. 用户可以修改 `Created`，并可填写 `End`。
7. 一旦用户填写了 `End`，系统必须再询问：
   > Should this Task be Closed or Deleted?
8. 用户选择：
   - **Closed** → Status = Closed
   - **Deleted** → Status = Deleted
9. 保存 `Created`、`End` 和新的 Status。

若用户在 Warning Dialog 选择 **No/Cancel**，不进入 End Time 编辑流程。

#### 情况 2：Task 已 Closed
- `End` 已有值。
- 点击 `Edit Time` 后，可直接修改 `Created` / `End`。
- Status 保持 `Closed`。

#### 情况 3：Task 已 Deleted
- `End` 已有值。
- 点击 `Edit Time` 后，可直接修改 `Created` / `End`。
- Status 保持 `Deleted`。

### Edit Time 规则
- 只在 Show All Data 提供 `Edit Time` Action Bar。
- Created 与 End 都可修改。
- Created 修改不会自动改变 Status。
- Active Task 的 End 原本必须为 Empty。
- Active Task 设置 End 后，必须选择 Closed 或 Deleted。
- 已 Closed / Deleted 的 Task 修改时间时保持原 Status。
- Edit Time 不允许产生 Active Status + 有 End 的不一致数据。
- 修改后的时间使用 Malaysia Time (UTC+8)。
- Edit Time 保存后刷新 Show All Data。

## New Task
1. `+ New Task`
2. 中央约800px Popup
3. Status 默认 KIV
4. Customer / Task Title 必填
5. Create 建立；Cancel/X 取消
6. 成功后关闭并刷新

## Edit Task
1. 点击 Task ID 或 Task Title
2. 中央约800px Popup
3. 显示全部字段
4. Task ID / Created / End 只读
5. 字段失去焦点即自动保存
6. 不显示 Save
7. X / Close 直接关闭
8. 关闭后刷新列表

> Note：一般 Edit Task 不允许修改 Created / End；需要调整时间时，必须通过 Show All Data 的 `Edit Time`。

## Search
- Contains、Case-insensitive
- 搜索：Task ID / Customer Name / Task Title / Task Description / Note
- 不搜索 Status / Created / End
- Enter 执行；清空后 Enter 恢复
- 无结果显示 `No results found`
- 切换 View 清除 Search

## Customer
- Dropdown 显示彩色圆点 + Name
- `+ Add Customer` 直接在 Dropdown 内新增
- ✓ / Add 建立，X 取消
- 新增后立即选中
- 每个 Customer 有 Edit 图标
- Name / Color Blur Auto Save
- 16 个固定 Fluent UI 风格色块，颜色不可重复
- API 自动新增 Customer 时使用第一个未使用颜色

## REST API
| Method | Endpoint | 行为 |
|---|---|---|
| POST | `/api/tasks` | Create |
| GET | `/api/tasks` | List |
| GET | `/api/tasks/{taskId}` | Read |
| PATCH | `/api/tasks/{taskId}` | Partial Update |
| DELETE | `/api/tasks/{taskId}` | Logical Delete |

Create 必填 Customer + TaskTitle；Description/Note 可选；Status 可选，默认 KIV。API Status 使用完整文字。Customer 使用 Name；不存在时自动建立。Response 直接 Resource JSON。400=Validation，404=Not Found。

## Excel
- 每个 View 顶部 Export
- 导出当前 View 当前显示结果
- 一个 Excel / 一个 Sheet
- `TaskTracker_[ViewName]_YYYYMMDD.xlsx`
